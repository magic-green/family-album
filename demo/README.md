# 示例剪贴画素材

本目录下的 `*.svg` 是**程序化绘制的示例剪贴画**，用于文档说明和界面占位，可自由替换或删除。

- 全部为纯 SVG 矢量图形（矩形、圆、椭圆、路径、渐变等几何元素），共 8 张，统一 `640×480` 画幅，奶油 / 蜜桃 / 蜂蜜色系。
- **不含任何真实照片、人物、文字、日期、设备信息、GPS 或 EXIF 数据**；不含位图嵌入、base64、外部链接与脚本，可离线打开。
- 主题：阳光与云、云朵、小花、小鸭、气球、星星与月亮、彩虹、相机。

如果你要换成自己的素材，把同名 SVG 替换掉即可；也可以把它们复制到前端静态资源目录使用。运行 `scripts/seed_demo.py` 生成的示例相册图片同样是由代码绘制的抽象卡通图，与本目录的剪贴画没有对应关系，全部为虚构内容。
